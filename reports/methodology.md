# Methodology

This project follows an end-to-end quantitative research workflow:

1. Data collection using `yfinance`
2. Data cleaning, stationarity checks, and feature engineering
3. Multi-model forecasting (ARIMA/SARIMA/Holt-Winters/Prophet/LSTM/Baseline)
4. Volatility and risk analytics (rolling vol, GARCH, VaR, drawdown)
5. Portfolio optimization and rebalancing strategies
6. Trading signal generation and backtesting
7. Model and strategy evaluation
